Plain-English guide to every figure on this page

Opening book balance
What the records say we had at the very start of the chosen period. For this worked example, a fixed starting figure (5 kg) — not computed, simply the period's starting point.
Receipts (RECEIPT_IN)
Everything physically delivered and posted against this material in the period. This is the one figure this ERP can already compute for real today.
Issues
Material handed out of the store for use (e.g. to a manufacturing batch). Proposed only — no issue feature exists yet.
Returns
Unused material physically brought back to the store. Proposed only — no return feature exists yet.
Closing book balance
Opening + Receipts − Issues + Returns ± Adjustments, for the chosen period. What the paper records say should be there right now.
Physical count
What someone actually counted, by hand, on a specific date. Always tied to the date it was counted — never averaged with a count from a different date.
Difference awaiting review
Physical count minus book balance. Shown as a plain number needing a human look — never automatically called wastage, theft, or process loss.
Simulated adjustment
A demonstration-only, clearly labelled correction that would bring the book balance in line with a physical count, were this a real system — original count and the adjustment both stay visible, nothing is erased.
