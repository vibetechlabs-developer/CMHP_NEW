      Regenerating This Dashboard

      This page embeds a static snapshot of the API (api-data.json, also published alongside this file for reuse). When backend endpoints change, regenerate as follows:

      1. Re-run a resolver walk against the live codebase (django.urls.get_resolver(), walking every pattern, checking which of GET/POST/PUT/PATCH/DELETE each view class actually implements) to get the current path/operation list.
      2. Diff that list against api-data.json's operations array (same method+path pairs) to see what changed.
      3. Update the corresponding module_*.py generator file (see docs/api-dashboard/README.md for the file layout) and re-run build.py to regenerate api-data.json.
      4. Re-embed the JSON into index.html (the build script does this in one step) and re-open the file in a browser to verify the counts on the Overview cards match the new resolver walk.

      No server, npm install, or network access is required at any point — the generator is plain Python using only the Django project already on disk.
